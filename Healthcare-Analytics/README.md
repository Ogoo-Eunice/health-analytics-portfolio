*A Data-Driven Review of Hospital Activity and Patient Outcomes* 

This project explores hospital encounter data to understand patterns in patient admissions, treatment expenditure, readmissions, length of stay, and patient satisfaction.

The purpose is to turn healthcare records into useful information that can help healthcare organisations monitor performance and make informed operational decisions.

Tools and Technologies

- Microsoft Excel: Dataset handling and initial inspection.
- Power Query: Data preparation and quality checks.
- Microsoft Power BI: Data modelling, visualisation, and dashboard development.
- DAX: Creation of calculated columns and analytical measures.

Dataset Description

The dataset contains 500 hospital encounters and 14 original columns, including patient demographics, medical conditions, admission types, hospitals, treatment costs, length of stay, insurance providers, readmission status, and satisfaction scores.

Data quality checks showed 500 unique encounter IDs, with no empty or error values reported in the initial validation.

Analysis Performed

The analysis included:

1. Patient encounter volume across medical conditions and admission types.
2. Average treatment cost across hospitals.
3. Overall patient readmission rate.
4. Patient encounters across different age groups and genders.
5. Hospital performance comparison using encounter volume, treatment cost, readmission rate, and patient satisfaction.
6. Patient satisfaction and average length of hospital stay.

An Age Group calculated column was created to classify patients into four age categories: 18–29, 30–49, 50–64, and 65+.

Key Findings

The dashboard revealed the following findings:

- Orthopedic recorded the highest number of Emergency admissions.
- St. Jude General had the highest average treatment cost.
- The overall readmission rate was 17.20%.
- Patients aged 30–49 years recorded the highest number of hospital encounters.

Dashboard Features

The interactive dashboard includes:

- Five KPI cards.
- Admission date range slicer.
- Hospital dropdown filter.
- Clear all slicers button.
- Medical condition and admission type analysis.
- Hospital treatment cost comparison.
- Insurance provider distribution.
- Age group and gender analysis.
- Hospital performance comparison matrix.

Conclusion

This project demonstrates how data analytics can transform healthcare data into meaningful insights. It highlights how data visualisation and analytical techniques can support hospital performance monitoring, operational assessment, and informed decision-making.

Skills Demonstrated

Data cleaning, data quality assessment, data modelling, DAX calculations, KPI development, interactive dashboard design, data visualisation, and healthcare data analysis.
